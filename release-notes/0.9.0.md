Postino 0.9.0 is in progress.

## What changes

### New

- **Workspace configuration file** (#215): `.postino/project.toml` holds the settings that belong to the workspace and are shared through git, starting with the order and colors of the environments. It is optional: a workspace without it works as before, and it is created with a new workspace or the first time you change something it holds.
- **Reorder environments** (#216): drag an environment in the Environments panel by its grip, or use Move up and Move down in its editor (`Alt+Up` and `Alt+Down`). The order applies to the environment picker, the command palette and the `Ctrl+1` to `Ctrl+9` shortcuts, and is saved in `.postino/project.toml`.
- **Refresh collections** (#219): a button in the Collections header, and a command palette action, read the workspace from disk again, to show changes made outside Postino, such as a `git pull` in a terminal.

### Fixes

- **Discarding changes refreshes the sidebar** (#218): discarding local changes in the Source Control panel, or reverting a block in a diff, now reads the workspace again, so a discarded new request leaves the collections tree and a restored one comes back, as after a pull.
