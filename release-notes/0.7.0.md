## What changes

### New

- **Git inside WSL** (#195): on Windows, a workspace kept inside WSL 2 (`\\wsl.localhost\<distro>\...`) uses the git of that distribution, through `wsl.exe`. It reads the repository on its own file system, with your Linux git configuration and SSH keys, and Git for Windows is no longer needed for it. Choosing `\\wsl.localhost\<distro>\usr\bin\git` in Settings, Git works too, and Settings shows the distribution next to the version.
- **Copy from the Console tree** (#197): click a row of the network tree to select it, then Ctrl+C (Cmd+C on macOS) copies its value, such as one header. Right click a row to copy its value, key or path. The arrow keys move through the tree and open or close branches.

### Polish

- **Console network entry** (#199): the method sits right before the URL (`GET https://...`) instead of in the column of the log lines.

### Fixes

- **Console tree with text bodies** (#196): a string with line breaks, such as a plain text body, no longer paints over the rows below it. Strings show on one row as JSON literals, with `\n` for each line break.
